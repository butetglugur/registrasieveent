=====================================================================
 PRESENSI EVENT v2 — PANDUAN INSTALASI (DirectAdmin / cPanel)
 PHP native, struktur ala Laravel, TANPA Composer, TANPA SSH.
=====================================================================

PERSYARATAN
-----------
- PHP 8.0 atau lebih baru (disarankan 8.2/8.3). Atur di panel:
  DirectAdmin: "Select PHP version" / cPanel: "Select PHP Version" / "MultiPHP Manager".
- Ekstensi: pdo_mysql, mbstring, json (biasanya sudah aktif), zip (untuk export Excel).
- MySQL / MariaDB.

LANGKAH 1 — BUAT DATABASE
-------------------------
DirectAdmin: Account Manager > MySQL Management > Create new Database.
cPanel     : MySQL Databases > buat database + user, lalu "Add User To Database"
             dengan ALL PRIVILEGES.
Catat: nama database, user database, password database.

LANGKAH 2 — UPLOAD FILE (pilih salah satu)
------------------------------------------
CARA A (paling mudah):
  1. Buka File Manager, masuk ke folder public_html domain/subdomain Anda
     (DirectAdmin: domains/NAMADOMAIN/public_html).
  2. Upload file ZIP ini, klik Extract.
  3. Pindahkan SEMUA ISI folder "presensi" ke public_html (termasuk file
     tersembunyi .htaccess). Struktur akhirnya:
        public_html/.htaccess
        public_html/index.php
        public_html/app/  bootstrap/  config/  database/  public/ ...
  File .htaccess otomatis mengarahkan request ke folder public/ dan
  MEMBLOKIR akses ke app/, config/, storage/, dll.

CARA B (paling aman, jika bisa mengatur document root subdomain):
  Upload folder "presensi" ke luar public_html, lalu arahkan document root
  domain/subdomain ke folder presensi/public.

CARA C (subfolder): ekstrak ke public_html/presensi — aplikasi diakses di
  https://domainanda.com/presensi (sudah didukung otomatis).

LANGKAH 3 — IZIN FOLDER
-----------------------
Pastikan folder berikut bisa ditulis (permission 755 biasanya cukup;
jika installer menyatakan tidak bisa ditulis, ubah ke 775):
  - storage/  storage/logs/  storage/sessions/  storage/cache/
  - config/

LANGKAH 4 — JALANKAN INSTALLER
------------------------------
Buka https://domainanda.com/install lalu isi:
  - Host database (biasanya localhost), nama DB, user, password.
  - Nama aplikasi, URL aplikasi, dan akun admin.
  - Centang "Impor data dari aplikasi versi lama" bila memakai database
    yang sama dengan versi lama: peserta (tabel attendees), link grup
    (tabel settings) dan akun admin lama (tabel admins) akan disalin.
    Tabel lama TIDAK dihapus.
Setelah selesai, installer TERKUNCI otomatis (file storage/installed.lock).
PENTING: jalankan installer SEGERA setelah upload — sebelum terkunci,
siapa pun yang membuka /install bisa melakukan instalasi.

LANGKAH 5 — SETELAH INSTALL
---------------------------
1. Aktifkan SSL (Let's Encrypt) di panel, lalu buka file .htaccess di root
   dan hapus tanda # pada 2 baris "Paksa HTTPS".
2. Login admin: https://domainanda.com/admin/login
3. Buat event > bagikan tautan / QR pendaftaran.
4. Hari H: buka menu Check-in di HP panitia, scan QR tiket peserta
   (kamera hanya berfungsi di HTTPS).

FITUR UTAMA
-----------
- Multi event, form builder (teks, paragraf, email, angka, tanggal, dropdown,
  pilihan ganda, checkbox), kuota, batas waktu daftar, tolak nomor WA ganda.
- E-tiket QR + tombol gabung grup WhatsApp + auto-redirect + simpan tiket PNG,
  cetak, bagikan, tambah ke kalender (.ics).
- Check-in via kamera (scan QR), input kode manual, pencarian cepat.
- Dasbor statistik, grafik 14 hari, filter & pencarian peserta, bulk action,
  export Excel (.xlsx) & CSV.
- Multi user: Administrator & Staf (staf hanya lihat peserta + check-in).
- Log aktivitas (audit), mode gelap, tampilan mobile-friendly.

KEAMANAN YANG DITERAPKAN
------------------------
CSRF token + cek Origin, prepared statement (anti SQL injection), escape
output (anti XSS), Content-Security-Policy, rate-limit login (5x/15 menit)
dan pendaftaran per IP, honeypot + time-trap anti-bot, password bcrypt,
regenerasi session saat login, auto-logout saat idle / password diganti,
export Excel aman dari formula injection, folder internal diblokir .htaccess,
error tidak menampilkan detail teknis ke pengunjung (log di storage/logs).

NOTIFIKASI PESERTA (v2.1) — ⚠️ INTEGRASI EKSTERNAL
--------------------------------------------------
Menu Admin > Notifikasi (khusus Administrator). NONAKTIF secara default.
Bila diaktifkan, setelah peserta mendaftar aplikasi MENGIRIM DATA PESERTA
(nama, nomor WA, email, kode tiket) ke layanan pihak ketiga pilihan Anda:
  - WhatsApp via Fonnte (api.fonnte.com) atau Wablas (server Wablas Anda)
    -> butuh akun & token dari penyedia (berbayar/berkuota).
  - Email via SMTP (mis. akun email hosting: mail.domainanda.com port 587)
    atau fungsi mail() server.
  - Webhook: POST JSON ke URL https milik Anda, ditandatangani header
    X-Presensi-Signature: sha256=HMAC(body, secret).
Pesan dikirim lewat antrean setelah halaman tiket tampil; bila gagal dicoba
ulang otomatis maksimal 3x dan bisa dikirim ulang manual dari riwayat.
Token/password disimpan terenkripsi (AES-256-GCM, kunci = APP_KEY di
config/env.php — jangan ganti APP_KEY atau token harus diisi ulang).
Risiko: WA gateway tidak resmi dapat membuat nomor pengirim diblokir
WhatsApp bila mengirim massal; pastikan peserta setuju dihubungi.
Upgrade dari v2.0: cukup timpa file (JANGAN timpa config/env.php); tabel
baru dibuat otomatis saat halaman pertama dibuka.

ANTI-BLOKIR WHATSAPP & PESAN MASSAL (v2.2)
------------------------------------------
Pesan WA TIDAK pernah dikirim sekaligus. Setiap pesan melewati "gerbang":
  - jeda acak antarpesan (default 20–45 detik),
  - istirahat setiap N pesan (default 5 menit tiap 15 pesan),
  - batas per jam & per hari (default 60/jam, 300/hari),
  - jam tenang opsional (mis. 21:00–07:00),
  - variasi kalimat {Halo|Hai|Selamat pagi} agar tiap pesan tidak identik.
Menu "Pesan Massal": kirim pengingat ke semua / belum hadir / sudah hadir,
lengkap dengan perkiraan lama pengiriman dan tombol "Batalkan antrean".
Saran nomor baru: jeda 30–60 detik, 30/jam, 150/hari, lalu naikkan bertahap.
Semua ini MENGURANGI risiko, tidak menjamin nomor tidak diblokir.

AGAR ANTREAN BERJALAN — PASANG CRON (disarankan, tanpa SSH):
  DirectAdmin: Advanced Features > Cron Jobs  |  cPanel: Cron Jobs
  Jadwal   : * * * * *  (setiap menit)
  Perintah : php /home/USER/domains/DOMAIN/public_html/cron.php
  (path lengkap yang benar ditampilkan di menu Admin > Notifikasi)
  Alternatif bila perintah php tidak tersedia:
    wget -q -O /dev/null "https://DOMAIN/cron/TOKEN"   (URL ada di menu Notifikasi)
Tanpa cron, antrean hanya berjalan saat ada pengunjung/pendaftar atau saat
halaman Admin > Notifikasi dibiarkan terbuka.

PENGINGAT H-1 (v2.3) — ⚠️ memakai kanal notifikasi yang sama (pihak ketiga)
--------------------------------------------------------------------------
Aktifkan di Admin > Notifikasi > "Pengingat H-1" dan atur jam kirim (default 09:00).
  - Dikirim sehari sebelum acara pada jam tersebut, lewat WhatsApp/email yang aktif.
  - Hanya untuk peserta yang mendaftar LEBIH DARI 1 HARI (24 jam) sebelum acara
    dimulai dan sudah terdaftar sebelum jam pengingat. Pendaftar mepet sudah
    menerima pesan konfirmasi, jadi tidak diingatkan lagi.
  - Sekali per peserta; ikut jeda anti-blokir; otomatis dibatalkan bila belum
    terkirim saat acara dimulai. Bisa dimatikan per event (form event).
  - Jadwal & estimasi 7 hari ke depan tampil di halaman Notifikasi, dengan
    peringatan bila estimasi pengiriman melewati jam acara.
  - WAJIB cron aktif agar pengingat terkirim tepat waktu.

Di luar fitur notifikasi, aplikasi tidak memanggil layanan eksternal.
Font & library QR sudah disertakan lokal (tanpa CDN).

MASALAH UMUM
------------
- Halaman 500 / putih: cek storage/logs/app-TANGGAL.log. Untuk debug
  sementara ubah 'APP_DEBUG' => true di config/env.php (kembalikan false!).
- 404 di semua halaman selain beranda: pastikan file .htaccess ikut terupload
  (aktifkan "show hidden files" di File Manager) dan mod_rewrite aktif.
- Lupa password admin: di phpMyAdmin jalankan
    UPDATE users SET password_hash = '<hash>' WHERE username='admin';
  (hash dibuat dengan password_hash() PHP) — atau hapus
  storage/installed.lock lalu jalankan /install lagi dengan username
  yang sama (data tidak hilang, password akan diganti).
- Instal ulang: hapus config/env.php dan storage/installed.lock.
